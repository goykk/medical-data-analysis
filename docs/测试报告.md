## 四、统计正确性验证说明

### 4.1 策略：不写死期望值，用独立路径交叉验证
每条统计结果都用**另一条独立的库调用路径**算出期望值再比对，而不是把数字硬编码进断言。
例如 `test_t_test_matches_scipy` 直接调用 `scipy.stats.ttest_ind` 与被测函数比对；
`test_logistic_matches_independent_statsmodels_reference` 直接 `sm.Logit(...).fit()` 与
`multivariable.run_multivariable` 的 OR / 95%CI / p **逐参数比对**（rel ≤ 1e-4）。

### 4.2 检验方法自动选择
| 输入条件 | 断言的检验方法 | 用例 |
|---|---|---|
| 均正态 + 方差齐 | Student t | test_t_test_matches_scipy |
| Levene p<0.05 | Welch 校正（名称含 Welch，且 assumption_checks 标记未通过） | test_welch_used_when_variance_unequal |
| 存在非正态组（2 组） | Mann-Whitney U（U 值与 scipy 一致） | test_mann_whitney_used_when_non_normal |
| 3 组正态 + 方差齐 | One-way ANOVA（F、p 与 `anova_lm` 一致） | test_anova_matches_statsmodels |
| 3 组正态 + 方差不齐 | Alexander-Govern | test_alexander_govern_used_when_unequal_variance_multigroup |
| 3 组非正态 | Kruskal-Wallis | test_kruskal_used_when_non_normal_multigroup |
| 2×2 且期望频数<5 | Fisher 精确检验（OR 含 CI） | test_fisher_used_when_expected_frequency_lt_5 |
| 大样本 2×2 | 卡方（χ²、p 与 scipy 一致） | test_chi_square_matches_scipy |

### 4.3 FDR（Benjamini-Hochberg）
- `test_fdr_matches_statsmodels`：与 `statsmodels.stats.multitest.multipletests(method='fdr_bh')` 逐值比对；
- `test_correlation_...` / `test_screen_univariate_returns_fdr_and_ranks`：断言 `p_fdr ≥ p`（校正后不会变小）、结果按 `p_fdr` 升序；
- 端到端实例：模拟数据中"年龄"原始 p=0.045 但 **p_FDR=0.09 不显著**——验证了"结论以校正后为准"确实生效。

### 4.4 EPV（每个变量事件数）
- `test_epv_warning_on_rare_events`：构造稀有事件数据，断言 `epv < 10` 且 warnings 含 "EPV"；
- `test_moderate_sample_warns_but_still_models`：n=45 触发"样本量不足"警示但仍完成建模；
- `test_small_sample_is_skipped`：n=20 直接 `skipped=True`，返回"样本量严重不足"而不是硬算。

### 4.5 防数据泄漏
- **预处理泄漏**：`test_no_data_leakage_scaler_fitted_on_train_only` 断言 `StandardScaler.mean_`
  等于**训练集**列均值，且不等于全量数据列均值；
- **评估泄漏**：所有评估图表标题由后端写入 `n=测试集样本量`，用例断言
  `roc/calibration/dca` 的 title 与 `n_test` 一致；
- **校准泄漏**：`CalibratedClassifierCV` 只在 `X_train` 上 `fit`，再对 `X_test` 预测；
  训练集 `n≥1000` 用 isotonic、否则用 sigmoid（Platt），方法写入 `calibration_model`，
  `test_roc_calibration_dca_all_present_and_labelled` 断言 WDBC（训练集 427 例）走 `sigmoid`。

### 4.6 可复现
- `test_random_seed_fixed_and_reproducible`：同一数据集连续两次训练，最优模型测试集 AUC **完全相等**；
- `test_predict_is_reproducible`：同一新样本两次预测，类别与概率完全一致。

### 4.7 DCA 与 Hosmer-Lemeshow（已批准的手写例外）
两项无成熟库实现，按规范手写，并用**人工逐步算例**验证：

- HL：10 个样本分 2 组，手写每组的 O₁/E₁/p̄ 与 `H = Σ(O₁−E₁)²/(n_g·p̄·(1−p̄))`，
  逐项对上（2.142857 + 1.328511 = 3.471368），自由度 `max(1, g−2)=1`，p 值由 `scipy.stats.chi2.sf` 给出；
  另用 pandas 分组聚合的独立实现对 200 样本 / 10 组交叉验证；
  并用"完美校准"数据断言 p>0.05。
  **分组数不再写死 10**：`hl_groups(n)` 按样本量自适应（n<50→3，50–99→5，100–500→10，>500→20），
  `test_hl_groups_scale_with_sample_size` 与 `test_calibration_analysis_uses_adaptive_hl_groups` 锁定该行为。
- DCA：5 个样本、3 个阈值，手写 TP/FP 计数与 `NB = TP/n − FP/n·[pt/(1−pt)]`
  （0.393939 / 0.4 / 0.0），"全部干预"参考线同样逐点比对；另用 100 阈值点的独立循环实现交叉验证。

### 4.8 大模型（mock，不依赖真实 API）
- 盘古鉴权头断言为 `X-Apig-AppCode`；
- 密钥优先级：页面配置覆盖环境变量（通过捕获请求头验证）；
- 未配置时 `chat` / `test_connection` 均返回可降级结果，不抛异常；
- 401→"密钥错误"、404→"模型名称不存在"、URLError→"网络不通"；5xx 重试 3 次后放弃；
- 提示词：字段名中的 ```` ``` ```` 被剥离、声明为不可信数据、上下文长度受上限约束。

## 六、已知限制

1. 前端（原生 JS + ECharts）无自动化测试，仅有后端接口测试与浏览器手工回归；
2. 生存分析（Kaplan-Meier）、配对检验属 P2-常规，尚未实现（智能建模内已支持 Cox / 随机生存森林）；
3. 云上模式的 RDS / Redis / OBS 用例使用 fake 客户端验证接口一致性，
   真实联调需在华为云环境按 `deploy_huawei.md` 第 9 节自检清单执行；
4. 本地模式历史持久化接口已完成（`POST/GET /api/history`），前端历史页面属 P2-常规；
5. 多分类已支持 one-vs-rest 的 ROC / 校准 / DCA（DCA 为各类净获益宏平均），
   但不输出多分类的 Hosmer-Lemeshow 检验（单次 HL 只对二分类概率有定义）。
