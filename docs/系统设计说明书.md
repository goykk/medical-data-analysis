## 二、模块设计

### 2.1 validators.py —— 医疗校验与变量类型
- **词库**：按"人口学 / 体格与生命体征 / 实验室检验 / 诊断与疾病 / 分期分级与病理 / 治疗与用药 / 结局与随访 / 医疗场景"分组的中英文词库；英文按词边界匹配，中文按子串匹配。
- **判定规则**：① 常规规则（匹配度 ≥30% 且命中 ≥2 个字段）**或** ② 强临床指标规则（存在 `diagnosis / 结局 / 恶性 / 良性 / 肿瘤` 等强字段）。
  规则②专为 WDBC 这类"字段名多为形态学测量（`radius_mean` 等）、但含诊断字段"的数据集设计。
- **类型推断**：数值型 / 分类型 / 数字编码分类（整数取值、水平数 ≤10、唯一值占比 ≤5%）/ 日期 / 文本；
  ID 列与常量列自动 `excluded` 并记录原因。
- **ID 判定规则**（`validators._is_id_like`）：唯一值占比 >90% **且** 满足以下之一才算 ID——
  ① 字段名带编号特征（`id / no / code / 编号 / 序号 / 病案号` 等）；
  ② 取值全部为整数。
  带小数的连续测量值（如 WDBC 的 `perimeter_mean`，唯一值占比 0.92）**不判为 ID**，
  否则会把 30 个特征中的 18 个误排除。
- **日期型**：推断为 `datetime` 并标记 `excluded`（暂不参与统计建模），避免下游建模时静默出错。

### 2.2 analyzer.py —— 解析与经典统计
- **解析**：`parse_table(content, filename)` 统一入口，按扩展名分派；文本类按 `["utf-8-sig","utf-8","gbk","gb2312","latin-1"]` 顺序重试；SPSS/Stata 走 pyreadstat（临时文件中转）。
- **清洗**：`build_cleaning_report` 只报告不修改；`apply_cleaning` 按用户决策执行并记录 actions。
- **检验自动选择**（`compare_groups`）：

| 条件 | 检验 |
|---|---|
| 连续结局 · 2 组 · 均正态 · 方差齐 | Student t（CI 由 `CompareMeans.tconfint_diff` 给出） |
| 连续结局 · 2 组 · 均正态 · 方差不齐 | **Welch 校正 t** |
| 连续结局 · 2 组 · 非正态 | Mann-Whitney U |
| 连续结局 · ≥3 组 · 均正态 · 方差齐 | One-way ANOVA（`statsmodels` OLS + `anova_lm`） |
| 连续结局 · ≥3 组 · 均正态 · 方差不齐 | **Alexander-Govern**（Welch 型，`scipy.stats.alexandergovern`） |
| 连续结局 · ≥3 组 · 非正态 | Kruskal-Wallis H |
| 分类结局 · 2×2 · 期望频数 <5 | **Fisher 精确检验** |
| 分类结局 · 其他 | 卡方（Pearson） |

效应量全部取自库：η² 由 `anova_lm` 平方和分解；Cramér's V 用 `scipy.stats.contingency.association`；
OR 与 CI 用 `scipy.stats.contingency.odds_ratio().confidence_interval()`；Cohen's d 由 `CompareMeans.std_meandiff_pooledvar` 换算。

### 2.3 multivariable.py —— 多因素分析
- 二分类结局 → `sm.Logit`；连续结局 → `sm.OLS`；`PerfectSeparationError` 捕获为可读错误；
  未收敛或 OR 发散（>1e6）时返回警示 / `None`，**不把天文数字返回给用户**。
- 分类变量 `pd.get_dummies(drop_first=True)`，参照组写入 `coding.reference`。
- VIF 用 `statsmodels.stats.outliers_influence.variance_inflation_factor` 逐列计算并映射回原变量。
- 混杂提示：校正前后显著性不一致，或估计值变化 >10%（OR 用对数尺度、β 用原始尺度）。

### 2.4 ml_engine.py —— 机器学习
- 预处理封装在 `Pipeline(ColumnTransformer)` 内，**只在训练折上拟合**（有专门反泄漏测试）；
  `cross_val_score` 只在训练集上做 5 折交叉验证，测试集仅用于最终评估。
- 候选：逻辑回归（`class_weight='balanced'`）+ 随机森林（`class_weight='balanced_subsample'`）；
  回归为线性回归 + 随机森林回归。
- **最优模型选择**：性能差距 ≤0.02 时优先可解释模型（医疗场景）。
- 缺失值：仅剔除**结局**缺失的样本；特征缺失交由 Pipeline 内的 imputer 在训练折上拟合填补。
- 评估三件套：预测概率先用 `CalibratedClassifierCV` 在**训练集**上校准（训练样本 n≥1000 用
  `isotonic`，否则用 `sigmoid` 避免小样本过拟合），再在测试集上计算 ROC / 校准曲线 / DCA，
  所有标题注明 `n=测试集样本量`。多分类结局按 one-vs-rest 每类各算一条 ROC / 校准曲线，
  DCA 取各类净获益的宏平均，`roc.macro_auc` 为宏平均 AUC。
- Hosmer-Lemeshow 分组数随测试集样本量自适应（n<50→3，50–99→5，100–500→10，>500→20），
  避免小样本固定 10 组时每组不足 10 例、检验退化成噪声。
- 混淆矩阵：看板展示推荐模型的测试集混淆矩阵；智能建模赛马逐折记录矩阵并在报告中给出折均值
  （`metrics.confusion_matrices` / `metrics.confusion_matrix_mean` + `metrics.classes`）。
- SHAP：树模型 `TreeExplainer`、线性模型 `LinearExplainer`（背景数据取训练集变换后的前 200 行），
  独热哑变量按原变量聚合，蜂群图超 1000 点采样；单样本力图用 matplotlib 生成 base64 PNG。
- 持久化：`joblib` 保存 Pipeline + 特征清单 + 数值特征训练集 min/max + 类别字段取值；
  预测时比对范围给出外推警示；上传新数据集即失效。

### 2.5 storage.py —— 双模式适配
同一套接口 `save_history / list_history / cache_set / cache_get / put_object / get_object / object_url`，
内部按 `MODE` 选择 SQLite|RDS、内存|Redis、本地目录|OBS。**业务代码不感知模式**。

### 2.6 llm_service.py / prompts.py —— 大模型
- OpenAI 兼容接口；预设 DeepSeek / 通义千问 / 智谱 GLM / **华为云盘古（`X-Apig-AppCode`）** / 自定义。
- 密钥优先级：页面配置 > 环境变量 > 未配置；只存 `_CONFIG` 内存字典，响应不回传密钥。
- 超时 20s、最多 2 次重试；4xx 不重试；失败分类为 `not_configured / http_error / network_error`。
- 提示词集中在 `prompts.py`；字段名转义后声明为"不可信数据"；上下文长度设上限。

## 五、双模式设计

| 维度 | 本地模式 | 云上模式 |
|---|---|---|
| 触发 | `MODE=local`（默认） | `MODE=cloud` |
| 数据集 | 内存中的"当前活动数据集"，数据不出本机 | 同上，但可经 OBS 持久化 |
| 历史 | SQLite（`backend/data/history.db`） | RDS for MySQL（表结构自动创建） |
| 缓存 / 任务状态 | 进程内存字典（带 TTL） | DCS Redis（`setex`） |
| 对象 | 本地目录 `backend/data/objects/` | OBS 桶（`datasets/` `models/` `static/`）+ CDN |
| 前端 | Node Express（3001） | OBS 静态托管 + CDN |
| 后端 | 本机 uvicorn（8002） | ECS + systemd |
| 告知 | README 与页面声明"数据不出本机" | **页面顶部黄条 + README 明示"数据将上传至华为云，由使用者确认"** |

实现要点：差异只在 `config.py` 的环境变量读取与 `storage.py` 的适配层，两者对外接口完全一致，
业务代码行`if mode == 'cloud'`仅出现在适配层内部。

## 六、技术选型理由

| 选型 | 理由 |
|---|---|
| FastAPI | 自带 OpenAPI 与 pydantic 校验；异步友好；CORS 中间件配置明确 |
| pandas / scipy / statsmodels | 统计计算的事实标准，避免手写公式带来的正确性风险 |
| scikit-learn Pipeline | 把填补、编码、标准化与模型封装为单一对象，从机制上杜绝"划分前拟合全量"的数据泄漏 |
| SHAP（Tree/LinearExplainer） | 医疗场景强调可解释性；禁用 KernelExplainer 以保证性能 |
| shap 力图用 matplotlib 出 base64 | 避免前端引入 SHAP JS 依赖，保持前端轻量 |
| ECharts | 国内 CDN 可用、图表类型齐全、支持 `getDataURL` 一键导出 PNG |
| 原生 JS（无框架） | 信息密度高的工具型界面，DOM 操作直接可控，避免引入大型框架 |
| SQLite（本地） | 零运维单文件，符合"数据不出本机"合规要求 |
| 华为云 RDS / Redis / OBS / ECS / 盘古 | 满足赛题"基于华为云产品构建并完成部署"与"大模型优先选用盘古"要求 |

## 七、准确性与合规设计

1. **禁止手写统计公式**：仅 DCA 与 HL 为例外，二者配手工逐步算例测试（`tests/test_dca_hl.py`）；
2. **防数据泄漏**：预处理只在训练折拟合；评估指标一律测试集；有专门断言比对 scaler 的 `mean_` 与训练集均值；
3. **防 AI 编造**：提示词附带原始数值并要求一一对应；后端程序化提取生成文本中的数字与计算结果比对，
   不一致则丢弃该次生成并降级为模板解读；输出显著标注"AI 生成，仅供参考，以实际计算数值为准"；
4. **XSS 防护**：前端 `esc()` 对所有数据集文本字段与 AI 返回内容转义后渲染；
5. **CORS**：仅允许 `FRONTEND_ORIGIN` 白名单，代码内不含 `"*"`（有用例断言）；
6. **密钥**：只存内存、不回传、不写日志；`.env.example` 提供模板，`.gitignore` 排除 `.env`。
