# 演示视频分镜脚本（主线：WDBC 乳腺癌数据集，一镜到底）

- 时长目标：**6 分 30 秒 ± 30 秒**
- 画面：1920×1080，浏览器全屏（http://127.0.0.1:3001），后端 http://127.0.0.1:8002
- 节奏：不剪辑跳转，鼠标连续操作；每屏停留 ≥3 秒便于评委看清数值
- 旁白风格：专业、克制，不夸大模型能力，所有结论以页面数值为准

---

## 第 0 屏：片头（0:00–0:20）

| 项目 | 内容 |
|---|---|
| 画面 | 平台首页（数据上传页），左侧导航 + 顶栏，右上角 AI 指示灯显示"AI 未配置" |
| 标注 | 红框圈住「AI 未配置」灯 |
| 旁白 | "医疗数据分析平台，一个面向临床科研的统计分析工具。请注意右上角——**没有配置任何大模型密钥时，平台全部统计与建模功能依然可用**，AI 功能会自动降级为模板解读。" |

## 第 1 屏：加载 WDBC 示例数据（0:20–0:55）

| 项目 | 内容 |
|---|---|
| 操作 | 点击「使用示例数据体验」→ 选择 **WDBC 乳腺癌数据集** |
| 画面 | 上传页 → 自动跳转数据确认页；字段表 32 行 |

| 旁白 | "我们直接加载内置的 WDBC 乳腺癌数据集：569 例，32 个字段。系统自动排除了 `id` 这类 ID 列（字段名带编号特征、取值近乎唯一），避免它被误当作分析变量；而 `perimeter_mean` 这类虽然取值也近乎唯一、但带小数的连续测量值，会被正确保留下来参与分析。" |

## 第 3 屏：数据清洗（1:25–2:00）

| 项目 | 内容 |
|---|---|
| 操作 | 查看清洗报告 KPI 卡；重复行选择「剔除重复行」；异常值保留默认「保留（仅标注）」；点击「确认清洗并进入分析配置」 |
| 画面 | 4 个 KPI 卡（样本量 / 重复行 / 总体缺失率 / 异常字段数） |
| 标注 | 红框：缺失率与"按成对删除处理"说明 |
| 旁白 | "清洗页给出重复行、缺失值与异常值报告。WDBC 没有重复行和缺失，我们保持默认——**缺失值默认按成对删除处理，每项分析单独报告实际纳入样本量**，这一点会写进最终报告。" |

> 备选镜头（如用模拟医疗数据集演示清洗）：重复行 2 条、空腹血糖缺失 15 例、超参考区间异常值 18.6 mmol/L。

## 录制注意事项

1. 录前先跑 `cd backend && python -m pytest -q`，确保 328 项全部通过，避免演示中出现异常；
2. 演示用 WDBC **10 个 mean 特征**即可（训练快、AUC 已 >0.9），避免等待；
3. 每次刷新页面后需重新加载示例数据（本地模式数据集只存内存）；
4. 全程不要出现任何真实患者信息；
5. 如参赛要求展示云上模式，补录 20 秒：设置 `MODE=cloud` 后页面顶部出现
   "云上模式：数据将上传至华为云，由使用者确认"黄条 + `/api/config` 返回 RDS/Redis/OBS。
