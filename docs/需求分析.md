# medical-data-analysis/docs/需求分析.md

## 一、背景与痛点

临床科研人员在完成数据收集后，常需要在有限时间内完成"数据清洗 → 统计检验 → 多因素校正 →
建模验证 → 成文"的整条链路。现有方案存在四类典型痛点：

| 痛点 | 具体表现 |
|---|---|
| 工具割裂 | Excel 清洗、SPSS 检验、Python 建模、GraphPad 绘图各成一套，数据在多个软件间反复导出导入，版本易错、过程不可复现 |
| 门槛高 | SPSS 点选式操作难以固化流程；直接写代码又要求使用者同时掌握 pandas / scipy / sklearn |
| 统计误用 | t 检验与 Mann-Whitney、卡方与 Fisher、方差齐性与 Welch 校正的选择条件常被忽略；多重比较不做 FDR 校正导致假阳性 |
| 结果不可信 | 部分 AI 工具直接让大模型"算"统计值，数字来源不可追溯；评估指标在训练集上计算，形成数据泄漏 |

## 二、目标用户

1. **临床医生 / 研究生**：无编程背景，需要快速完成一篇回顾性研究的统计分析；
2. **医学统计初学者**：需要被明确提示"该用什么检验、前提是否满足、结论能说到什么程度"；
3. **科研团队**：需要可复现、可导出的分析流程与标准化报告。

## 三、功能需求

### 3.1 P0 基础分析（必须）
| 编号 | 需求 | 验收要点 |
|---|---|---|
| F1 | 文件解析 | 支持 csv/xlsx/xls/tsv/txt/json/sav/dta；文本类自动检测编码并重试；失败给出明确原因 |
| F2 | 医疗数据校验 | 中英文医学词库匹配；不足时提供「终止分析 / 确认继续」两个选项；手动放行在报告中注明 |
| F3 | 变量类型确认 | 展示「字段名 + 推断类型」清单供确认；数字编码分类变量不得按数值处理；自动排除 ID 列与常量列。ID 判定需同时满足「唯一值占比 >90%」与「字段名带编号特征或取值为整数」，带小数的连续测量值不得误判为 ID |
| F4 | 数据清洗 | 检测重复行、缺失值、医学合理范围异常值；剔除/保留由用户确认并记录；缺失按成对删除，每项分析注明实际纳入样本量 |
| F5 | 描述性统计 | 数值变量：均值、标准差、中位数、四分位数、极值；分类变量：频数与构成比 |
| F6 | 正态性检验 | Shapiro-Wilk；n>500 结果仅作参考，结合直方图 / Q-Q 图 |
| F7 | 单变量组间比较 | 自动选检验；t / ANOVA 前做 Levene，不齐自动 Welch；卡方期望频数 <5 自动 Fisher；报告效应量、95%CI、统计量、p |
| F8 | 相关性分析 | 相关系数矩阵 + 热力图 |
| F9 | 参考区间叠加 | 常见检验指标叠加医学参考区间，常量集中定义并注明依据 |
| F10 | 多因素分析 | 分类结局 Logistic / 连续结局线性回归；调整 OR 或 β、95%CI、p；哑变量注明参照组；VIF>10 提示；校正前后对照与混杂提示 |
| F11 | 可视化 | 直方图、箱线图、热力图、柱状图、森林图、特征重要性图、SHAP 图，每张可下载 PNG |
| F12 | 文字解读 | 单项结果即时模板解读；前提不满足时返回局限性说明而非强行计算 |
| F13 | 报告导出 | 固定结构汇总，前端打印转 PDF |

### 3.2 P1 智能分析与机器学习（必须）
| 编号 | 需求 | 验收要点 |
|---|---|---|
| F14 | 结局变量识别 | 词库扫描推断候选，用户确认；未指定不强行训练；分类走分类、连续走回归 |
| F15 | 重要指标筛选 | 同时给出原始 p 与 FDR 校正 p，以校正后为准；单变量结果仅作描述，特征选择须在交叉验证内部完成；按重要性降序，次要指标折叠 |
| F16 | 机器学习建模 | sklearn Pipeline；分类逻辑回归 + 随机森林，回归线性回归 + 随机森林回归；分层划分 + 交叉验证（均值±标准差）；`class_weight` 处理不平衡；每类召回率；固定随机种子 |
| F17 | 评估三件套 | ROC + AUC + 约登截断值；校准曲线 + HL 检验（训练集 n≥1000 用 isotonic、否则 sigmoid，HL 分组数随样本量自适应）；DCA 净获益 + 全部干预/全不干预参考线；多分类按 one-vs-rest 每类一条曲线；全部基于测试集并展示混淆矩阵 |
| F18 | SHAP 可解释性 | 树模型 TreeExplainer、线性模型 LinearExplainer；哑变量按原变量聚合；超 1000 点采样；力图用 matplotlib 生成 base64 |
| F19 | 新样本预测 | 保存 Pipeline / 特征清单 / 训练集范围；返回类别或数值、概率、SHAP 力图；超范围外推警示；换数据集旧模型失效；pytest 验证可复现 |
| F20 | 样本量红线 | n<50 或 EPV<10 提示仅供参考；严重不足跳过建模 |

## 四、非功能需求

| 类别 | 要求 |
|---|---|
| 准确性 | 统计与建模一律调用成熟库；仅 DCA 与 HL 允许手写公式且必须配手工核算测试；前端不做任何计算 |
| 可复现 | 固定随机种子；依赖锁定主版本号；接口返回中标注随机种子与样本量 |
| 合规 | 免责声明；本地模式数据不出本机；云上模式明示；发给大模型的信息仅含字段名、类型与计算结果数值；示例数据全部模拟脱敏 |
| 安全 | CORS 仅允许固定来源，禁止 `*`；前端渲染数据集文本字段与 AI 返回内容前转义防 XSS；密钥不落盘 |
| 可用性 | 未配置密钥时项目正常启动，全部 P0/P1 功能可用，AI 自动降级 |
| 性能 | 单数据集 ≤ 10 万单元格时，分析接口响应时间控制在秒级；SHAP 蜂群图超 1000 点自动采样 |
| 可维护性 | 配置集中、函数职责单一、最小依赖集、目录结构标准（便于华为云 CodeArts 管理） |
| 可移植 | Python ≥3.10 / Node ≥18；本地与云上共用业务代码 |

## 五、不在本期范围内

- 多中心、队列级别的长期随访数据管理；
- 影像 / 基因组等非结构化数据的高级分析；
- 多用户账号体系与权限管理（本地模式按单用户设计）；
- 真实临床诊断级决策支持（本项目明确定位为科研辅助）。
